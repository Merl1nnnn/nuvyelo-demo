# Nuvyelo — тестовая сборка сайта

Готовый статический фронтенд: редактор, предпросмотр и экспорт установщика.
Серверная часть для этих функций не требуется. Проекты сохраняются в браузере.
Папки assets/fonts/wallpapers/installers нужны сайту и экспорту.
Установщики экспериментальные; ограничения указаны при экспорте.
Этот репозиторий содержит публичную сборку, исходный проект хранится отдельно.
